# API Plan

## Создание заметки

POST /notes

Создаёт новую заметку.

## Получение списка заметок

GET /notes

Возвращает список заметок.

## Получение одной заметки

GET /notes/{id}

Возвращает заметку по идентификатору.

## Изменение заметки

PUT /notes/{id}

Изменяет существующую заметку.

## Удаление заметки

DELETE /notes/{id}

Удаляет заметку.
