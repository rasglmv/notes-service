# Разрешение конфликта

## Где возник конфликт

Конфликт возник в файле README.md.

## Причина

В двух ветках была изменена одна и та же строка:

"Статус проекта"

В ветке feature-status-a использовался вариант:

"Статус проекта: Готовится к тестированию"

В ветке feature-status-b использовался вариант:

"Статус проекта: Активная разработка"

## Как был решён конфликт

Git не смог автоматически определить,
какой вариант необходимо оставить.

Конфликт был открыт в README.md и исправлен вручную.

В итоговой версии оставлен вариант:

"Статус проекта: Активная разработка"

После исправления файл был добавлен командой git add,
а результат был сохранён отдельным commit.
