# Сервис заметок

Статус проекта: Активная разработка

## О проекте

Сервис заметок предназначен для создания, хранения,
редактирования и удаления личных заметок.

## Основные возможности

- создание заметки;
- просмотр заметок;
- редактирование заметки;
- удаление заметки;
- поиск заметок.

## Технологии

На текущем этапе проект используется для демонстрации
работы с Git и GitHub.



## Интерфейс

Пользователь сможет просматривать список заметок
и открывать отдельную заметку для редактирования.
