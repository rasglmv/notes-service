# План проекта

## Название

Сервис заметок

## Цель

Создать простой сервис для хранения и управления
личными заметками.

## Основные функции

1. Создание заметки.
2. Просмотр заметок.
3. Редактирование заметки.
4. Удаление заметки.
5. Поиск заметок.

## Пользователь

Пользователь сервиса может создавать и изменять
свои заметки.
